## 使用场景

这两个文件是旧版辽大样本规则的重要历史来源；当前主 profile 已统一为 `lnu-checker-2026`，旧 `lnu-undergraduate` 命令入口已移除。若这些旧样本与 2026-05-01 最新截图或当前 profile 冲突，以最新截图和当前 profile 为准。它们主要用于：

- **新规则校准**：遇到新的格式要求（表格、图、公式等），先查阅这两个文件确认标准值，再更新 profile
- **历史规则追溯**：当检查结果与旧文档经验冲突时，用它们定位差异来源，但不覆盖最新截图规则
- **Profile 扩展**：未来添加新模块（如附录格式、页眉页脚细节）时，从这里提取数据
