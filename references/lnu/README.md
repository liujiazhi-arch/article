## 使用场景

这两个文件是 `lnu-undergraduate` Profile 的唯一数据来源，用于：

- **新规则校准**：遇到新的格式要求（表格、图、公式等），先查阅这两个文件确认标准值，再更新 profile
- **规则争议仲裁**：当检查结果与用户预期不符时，以这两个文件为准
- **Profile 扩展**：未来添加新模块（如附录格式、页眉页脚细节）时，从这里提取数据
