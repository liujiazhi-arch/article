# 辽大后置部分规则

来源：

- 2026-04-09 截图组中的致谢页
- 前序轮次已确认的参考文献样图与真实文档处理结果
- 当前 `lnu-undergraduate` profile

## 1. 参考文献标题

- 标题：`参考文献`
- 居中
- 黑体
- 三号
- `1.5` 倍行距
- 段前 `0`
- 段后 `0`
- 应单独分页起页

注意：

- 真实文档中可能出现 `——` 等占位符，不能只检查条目，必须同时检查标题。

## 2. 参考文献条目

- 编号格式：
  - `[N]`
  - 编号后一个半角空格
- 禁止：
  - `[01]`
  - 多个空格
  - `Tab`
- 对齐：
  - 悬挂缩进
  - `left_indent = 420`
  - `first_line_indent = -420`
- 字体：
  - 中文宋体
  - 英文与数字 `Times New Roman`
- 字号：
  - 五号
- 行距：
  - `1.5` 倍
- 段前：
  - `0`
- 段后：
  - `0`
- 标点：
  - 使用英文半角

## 3. 附录

- 当前截图组没有提供附录专项样图
- 当前已知：
  - 附录应作为后置部分
  - 应单独分页起页
- 进一步版式细则仍待后续截图补全

## 4. 致谢

- 标题：`致  谢`
  - 黑体
  - 三号
  - 居中
  - `1.5` 倍行距
  - 段前 `0`
  - 段后 `0`
- 标题双字之间保留两个字符间距
- 正文：
  - 仿宋
  - 小四
  - `1.5` 倍行距
- 当前截图说明：
  - 落款名字自行调整
  - 无具体位置限制

## 5. 后置部分分页规则

- 参考文献、附录、致谢应使用分页符另起一页

## 6. 当前结论

- 参考文献条目版式要求已经稳定，可视为辽大主链已收口。
- 参考文献标题占位符识别、附录专项细节，仍需后续继续补强。
